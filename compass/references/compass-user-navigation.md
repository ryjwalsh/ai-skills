# Compass web client navigation (v2.2.10.x User Guide)
Source: https://d8eqw8u9b6kgn.cloudfront.net/documents/MSI-Compass-On-Prem-User-Guide.pdf, extracted 2026-09-14. Compass is a PSIM / decision-management console: alarms from integrated systems (video, access, intrusion, SNMP) are handled with operator guides (SOPs).

- Main areas: **Live Site** (remote site devices/cameras), **Alarms** (left alarm panel), **Workspace** (header; cards for alarms in progress, guard tours, open sites, mosaics), **Video Wall** (Layouts tab: New/edit/delete layouts; monitor types Spot / Alarm / Mosaic; joystick), **Mosaics** (upper-right icon: list, New, +cameras by site, Send to Mosaic), **Maps** (Google Maps / GeoServer / offline OpenStreetMap; layers Sites/Labels/Alarms; floatable Dynamic/Static; swap geographic layer; search address/site).
- **User Menu** (upper right): Reports (New On-Demand: site, dates, Real/Test alarms, filters Behaviors/Alarm Types/Classifications/Priorities/Sources → PDF/Excel/email; New Automatic Report: schedule Daily/Weekly/Monthly, format, contents; Configured Automatic Reports tab), Auditing (audit trail, Business Intelligence via Kibana, reports repository), **Configuration** (system setup - Sites (contacts, floor plans, coverage areas, pre-configured alarms, mobile sites need a GPS device), Global Devices (drivers/integrations), Users/Roles, System properties (alarm entry hours, operator groups, filters, timeouts, exclusive cluster, GPS coordinates, retention default 90 days alarms / 30 days media), Private/Public Host IP), Other > Threat Levels / Inhibit alarm source / Site state / Active sites / Occupancy / Bookmarks / Multinode (failover status, 10-s refresh).
- Alarm priorities Critical / Major / Minor / Warnings. Alarm panel order: handled → locked cluster → active → mine → locked by others → postponed → others'.
- Operator flow: select alarm (panel or map) → live video + trigger device + floor plan → follow Operator Guide tasks (confirmation, options, form, call/email contact, device interaction, grant access, inhibit source, search access control/contact) → pre/post-alarm video, video search (24 hourly → 5-min thumbnails) → **Clear** (comment + classification False/Real/Test) or Postpone (5 min…Forever, comment; re-activates with indicator) or Escalate (new alarm type/operator guide) or Change priority. Exclusive cluster: "This alarm has already been assigned to another Operator". Timeout warning one minute before.
- Devices tab (side menu): request video, toggle inputs/outputs, place calls, inhibit detectors/alarm sources; icon colours blue (no interaction) / red-green (toggle) / grey (unknown); hover camera for reference image.
- Guard tours (scheduled → alarm entries; on-demand), VoIP/intercom alarm extensions, Smart Site Protection style monitoring.
- Errors: "No resources available" (overload), "LIVE stream lost or finished by source" (camera/network).
