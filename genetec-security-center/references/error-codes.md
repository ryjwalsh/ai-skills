# Error codes and messages

Phase 2 section I, message-first. **There is no single published error-code catalogue for Security Center in the retrieved sources.** What exists is a set of exact messages, numeric installer codes, health-event names and internal defect IDs, gathered here verbatim. The absence of a consolidated catalogue is recorded in `../known-gaps.md`.

## 2. Numeric installer and Windows codes

| Code | Context | Meaning and action | Src |
|---|---|---|---|
| `1603` | Security Center silent installation | Generic fatal install error. Documented specific cause: `/ISInstallDir` value ends with a trailing backslash. Remove it. Review logs at `C:\ProgramData\Genetec\Installation`. Documented as a Security Center limitation. | S28 |
| `1603` | Genetec Update Service (GUS) upgrade | Same generic meaning. Documented specific cause: the existing Security Center install path ends with a trailing backslash. Workaround: download the installers and upgrade each machine individually. To be fixed in a future GUS release. | S29 |
| `0x800f081f` | Microsoft .NET Framework during Security Center installation on Windows 11 | .NET Framework 3.5 cannot be enabled because .NET 3.5.1 files are missing. Run `DISM /online /enable-feature /featurename:NetFx3 /All /Source:F:\sources\sxs` from mounted Windows media, enable **.NET Framework 3.5** in Windows Features, re-run the install. | S7 |
| `0x800f0906` | Microsoft .NET Framework on Windows Server 2012 / 2012 R2 | .NET 3.5 package failed to install. Use the Group Policy **Specify settings for optional component installation and component repair** workaround with an alternate source path `<drive>:\sources\SxS`. | S30 |
| **Event ID 41** | Windows System event log | Unclean shutdown; possible SQL or installation corruption. | S21 |
| Hotfix **2953969** | Archiver "Disk access unauthorized" | Required for 5.10.0.0 (after upgrading to 5.10.1.0) and for 5.10.1.0. Obtain it from GTAC. | S32 |
| Hotfix numbers generally | Build not in the published build-number tables | "If the build number is not listed in the following tables, you are most likely running a Security Center hotfix." | S13 |
