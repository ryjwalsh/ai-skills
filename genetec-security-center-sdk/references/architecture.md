# Architecture — Genetec Security Center SDK

Sources: S1 (Developer Guide 5.14), S3 (RN 5.14.0.0), S11 (DAP), S12–S18 (component overviews).

---

## 1. The toolkits, and when to use each [S1 "Data model for the Security Center SDK"]

| Toolkit | Runs where | Language/runtime | Use it for | Needs SDK connection? |
|---|---|---|---|---|
| **Platform SDK** | Your own Windows process (console, WPF, WinForms, Windows service, ASP.NET) | .NET Framework 4.8 / .NET 8.0 | The standard SDK: connect to and interact with the platform; Windows apps, services, GUIs | Yes — one per `Engine` logon |
| **Macro SDK** | **Inside the Directory role** | C# pasted into Config Tool | Simple, headless business logic on a schedule or event trigger; "removes the burden of implementing a complete .NET Windows service" | **No** — "Macros do not require any additional SDK connections" |
| **Workspace SDK** | Inside **Security Desk** / **Config Tool** | .NET Framework 4.8 | New UI tasks, tile views/widgets/properties, custom dashboard widgets, contextual actions, map layers. Ships a UI control/style library: `Genetec.Sdk.Controls.dll` | Yes — per registered component, per signed-in user |
| **Plugin SDK** | **Server-side role entity** + optional client component | .NET | Create your own role entity, similar to Archiver or Access Manager, "fully embedded within Security Center"; benefits from **failover and database support** | Yes — one per plugin role added |
| **Web SDK** | Any platform, over HTTP | Any language | Non-Windows integrations; "entirely decoupled", nothing installed on the client. Introduced in Security Center **5.0** | Yes — per request/session (see below) |
| **Media SDK** | Your own Windows process | .NET Framework 4.8 only | Video feeds, archives, export, PTZ, overlays | Yes + **Media SDK** license option |
| **Genetec Web Player (GWP)** | Browser (JS/TS) | JavaScript/TypeScript | Display Security Center video/audio in a web page via the Media Gateway | Uses a token bound to an SDK certificate |
| **Media Gateway RTSP** | Your app acts as an RTSP client | Any | Raw RTP/RTSP streams; **you** decode and render | SDK used only to obtain camera GUIDs |

Scope note [S1]: "The objects and methods documented in this help file are supported by Genetec. The use of undocumented methods and objects is entirely at your own risk, and Genetec does not guarantee the forward or backward compatibility of those methods or objects."

## 2. Platform SDK internals [S1 "Architecture of the Platform SDK"]

The SDK "allows you to communicate through a **TCP channel** to the SC Directory from your application." Four building blocks:

### 2.1 Engine
Root class of the SDK. Gives access to every manager, manipulates entities, receives events, and launches authentication against the Directory.
**Create only one instance per project** — "to avoid multiple communication channels to the directory." [S1]

### 2.2 Entities
The Directory stores all system configuration as **entities**, representing either physical devices (cameras, doors) or conceptual objects (macros, applications, schedules). **Each entity has a unique `Guid`.** Enumerated by `EntityType`. "The SDK is built around the 'entity' concept. Every call made by the SDK manipulates the corresponding entity inside the Directory." [S1]

### 2.3 Events
Real-time data generated by the system. **Roles produce events and log them in their own databases**, so applications can query them later. Enumerated by `EventType`. [S1]

### 2.4 Managers (reached from `Engine`) [S1]

| Manager | Responsibility |
|---|---|
| `ActionManager` | Send actions to Security Center for processing |
| `AlarmManager` | Trigger and acknowledge alarms |
| `IncidentManager` | Create, send, retrieve incidents |
| `ReportManager` | Report generation. Two families: **entity configuration** reports (e.g. all cardholders named David) and **activity** reports (e.g. all events from camera XYZ). Enumerated by `ReportType` |
| `SecurityManager` | Check privileges granted to the signed-in user (`IsPrivilegeGranted`) |
| `TransactionManager` | Group many entity modifications into one transaction. Not required for single edits; "if your application creates, deletes, or modifies many entities, your application might become slow" |
| `LoginManager` | Logon/logoff and the `LoggedOn`/`LoggedOff`/`LogonFailed`/`LogonStatusChanged` events |

## 3. Inter-component communication

| Path | Transport | Notes | Source |
|---|---|---|---|
| Platform SDK → Directory | **TCP 5500**, encrypted with **TLS** (since Security Center 5.4 GA) | Authenticated with a Genetec-provided SDK certificate + Security Center user credentials | S1 |
| SDK video streaming | **RTSP + RTP**; unicast UDP 6000–6200, multicast UDP 47806/47807, requests TCP 554/560 | Media SDK uses the same codecs as Security Center client applications | S1 |
| Web SDK client → Web-based SDK role | HTTP on **4590**, HTTPS on **4591**; HTTP Basic auth | Responses XML or JSON (Newtonsoft since 5.8 GA) | S1 |
| Browser → Media Gateway (Web Player) | **WebSocket** over 80/443; token from `POST /v2/token/{cameraId}` | Library served from `<gateway>/v2/files/gwp.js` | S1 |
| RTSP client → Media Gateway | RTSP (RFC 2326) on **654** by default | `rtsp://<user:pass>@<IP>:<port>/<camera guid>/<stream>[?<attributes>]` | S1 |
| Macro → system | In-process inside the Directory role | "The .NET SDK provided to you is already logged as the admin user" | S1 |
| Workspace module → system | In-process inside Security Desk / Config Tool | Loaded via `.Plugin.xml` (5.13+) or registry (≤5.12) | S1 |

## 4. Databases

The SDK does not own a database. It reads and writes through the Directory and through role databases:

| Store | Relevance to SDK developers | Source |
|---|---|---|
| **Directory** database | Holds all entity configuration. `Engine.GetEntity` on an uncached entity causes a direct database fetch — "On a large system, repeatedly using `Engine.GetEntity` to fetch entities can cause the server and the Directory to crash." Use `EntityConfigurationQuery` to populate the entity cache instead. Server Admin reports when the Directory database needs an upgrade. | S1 |
| **Role** databases | Each role logs its own events; activity reports query these. | S1 |
| **Access Manager** database → `EventStream` table | Added in **5.11.0.0**. Queried by insertion timestamp via `AccessControlRawEventReportQuery`. **Off by default** — must be enabled with an advanced setting in Config Tool, and needs extra disk space. | S8 |
| SQL Server (optional, your app's logs) | `SqlServerLogTarget` can write your application's log entries to a SQL Server database. | S1 |

Exact schema, sizing and retention for these databases is **Not documented** in the SDK doc set — see `known-gaps.md`.

## 5. Dependency stack

### 5.1 Runtime [S1, S6]

| Security Center SDK version | Supported runtime |
|---|---|
| 5.12.1.0 and before | .NET Framework 4.8 |
| 5.12.2.0 and later | .NET Framework 4.8 **and** .NET Core (.NET 8.0) |

The .NET 8 build "isn't intended for use with Mac or Linux SDK applications. The references to WPF technology within the .NET 8 SDK aren't supported on Linux or Mac." `Genetec.Sdk.Media.dll` is **not available** in .NET Core. [S1, S6]

### 5.2 Third-party DLLs — Security Center 5.14.0.0 SDK [S3]
`Genetec.SDK.dll` depends on:
- Autofac **4.9.2**
- AutoMapper **8.1.0** (.NET Framework 4.8 edition)
- AutoMapper **12.0.1** (.NET 8.0 edition)
- Newtonsoft **13.0.3**

`Genetec.SDK.Controls.dll` depends on CefSharp **126.2.180.0**.

Doc warning: "Make sure that other applications that you use with the Security Center SDK applications all use the same versions of DLLs."

### 5.3 GPU / hardware acceleration [S1]
- "The Media Player supports hardware acceleration started from SC 5.9.1 SDK."
- Even so, "the SDK Media Player has slower performance compared to the Media Player in Security Desk. For the SDK Media Player, the GPU on the server is only used for the decoding while the rendering is done by the host process."
- Vendor-specific accelerator shims shipped with the SDK: `Genetec.Nvidia.dll`, `Genetec.QuickSync.dll` (both x86 and x64 variants).
- The Web Player advertises "Hardware accelerated video decoding (when available)."
- **No minimum GPU model, driver version, VRAM or CPU/RAM figure is documented** anywhere in this doc set — see `known-gaps.md`.

## 6. Media SDK component model [S1]

| Component | Type | Purpose |
|---|---|---|
| `MediaPlayer` | **WPF UserControl** | Display video in a UI. Handles rendering. Supports audio through the computer speaker. Use for standalone apps, custom tasks, embedding video in third-party apps. |
| `VideoSourceFilter` | Back-end component | Access **decoded frames** in YUV or RGB (formats: RGB32, YUV420, YUV422, each with timestamp, height, width). Use for image analysis / video analytics — "recommended to avoid excessive CPU and memory usage from rendering." |
| `MediaExporter` | Exporter | Export archive video from Archivers to **`.g64`** and **`.g64x`** |
| `G64ToAsfConverter`, `G64ToMp4Converter` | Converters | Convert exported files to `.asf` / `.mp4` |
| `FileCryptingManager` | Crypto | Encrypt/decrypt video files |

Both `MediaPlayer` and `VideoSourceFilter` use the same codecs as Security Center client applications, decode video from all supported cameras, handle live and playback, and can play archive files. Out-of-process decoding spawns `GenetecServerHost32.exe` (count tracks CPU cores) and `GenetecMediaComponent32.exe` (count tracks streamed cameras).

**Media Gateway alternative**: it "provides the raw RTP video stream: it is the Tech Partner who is in charge of decoding and rendering the stream. Because some manufacturers use proprietary codecs, it might not be possible to decode the streams for certain camera manufacturers or models." Here the SDK is used only to retrieve camera identifiers to build the video URI. [S1]

Audio analytics is not directly supported; documented workarounds are exporting the file first, or playing through `MediaPlayer` to get audio output. [S11]

## 7. Workspace SDK service model [S1]

Retrieved with `Workspace.Services.Get<IXxxService>()`:

| Service | Purpose |
|---|---|
| `IAlarmService` | Acknowledge, snooze, get the alarm monitoring page |
| `IBadgeService` | Print badges |
| `IConfigurationService` | Show an entity's configuration in Config Tool (equivalent to the Security Desk "Show Configuration" menu) |
| `IContextualActionsService` | Register/manage contextual actions |
| `IContentBuilderService` | Build tile content from an input value (e.g. display a camera in a tile) |
| `IDialogService` | System dialogs: `ShowEntityBrowserDialog` (with entity-type filter, exclusions, single/multiple/extended selection), `ShowGeoPositionDialog` |
| `IEventService` | Add fields to the event description in the Monitoring task |
| `IGuardTourService` | Control guard tours |
| `IMapService` | Interact with maps; `RegisterLayer(new LayerDescriptor(guid, name))` |
| `IReportService` | Open a Report page in Security Desk |
| `IShellService` | Start applications: `service.Start(ApplicationType.ConfigTool)` |
| `ITaskService` | Run tasks; create a Monitoring task and set `Pattern = TilePattern.Create(1,1)` |
| `IVaultService` | Enumerate Vault items; `VideoItem` exposes watermark/encryption properties |
| `IWidgetService` | Manage dashboard widgets |
| `IService` | Base for your **own** service — register in `Module.Load`, unregister in `Unload` |

`IBackgroundProcessNotificationService` was exposed as an SDK service in **5.11.0.0** (add, clear completed, complete with success/warning/error, notify, update progress). [S8]

## 8. Supported topologies

| Topology | What the docs say | Source |
|---|---|---|
| SDK app **on** the Security Center server | Supported and simplest: "if your application runs on the server where Security Center is installed, there's no need to install the Genetec SDK" | S1 |
| SDK app on a **separate** machine | Supported; the Genetec SDK must be installed on that machine | S1 |
| ASP.NET / IIS hosting | Supported, with caveats: IIS **shadow copy** breaks assembly loading. Either set `<hostingEnvironment shadowCopyBinAssemblies="false"/>` in web.config, or use a `PreApplicationStartMethod` + `AssemblyResolve` initializer | S1 |
| **Plugin role with failover** | The Plugin SDK server-side component "benefits from having failover and database support" | S13 |
| **Media Gateway multi-agent** | A Role can have several Agents sharing one configuration. GWP connects to **one specific agent** by public address. "**You are responsible for load balancing between servers.**" Considerations named: current server load, resource sharing (streaming the same camera twice from the same server is more efficient), network topology/geography | S1 |
| Web page + Media Gateway | "The website displaying the library must be hosted on an independent web server", and both the page and the gateway must be reachable by the browser | S1 |
| Federated / Omnicast video | Requires the **Compatibility Pack ("CPack")** on the client machine + extra post-build copies + a reboot. `SetVisualTrackingConfiguration` is not supported for federated cameras (limitation 240792) | S1, S3 |
| Cloud / hybrid | **Not documented** in the SDK doc set | — |
| HA/clustering for the Directory | **Not documented** in the SDK doc set (Administrator Guide territory) | — |

## 9. Adjacent modules that directly affect SDK work

Only these are in scope, per the "mention adjacent modules only where they directly affect it" rule:

| Module | Why it matters | Source |
|---|---|---|
| **Directory** | Sole authentication and configuration endpoint for the Platform SDK; hosts macros; enforces the three-major-version backward-compatibility window | S1 |
| **Web-based SDK role** | Hosts the Web SDK web service; owns the Port and Base URI settings; must be created manually | S1 |
| **Media Gateway role** | Serves the GWP library, tokens, WebSocket streams and RTSP; owns CORS and transcoding settings | S1 |
| **Access Manager** | Owns the `EventStream` table; a cardholder deleted while it is offline still reports as present in the area (limitation 3819660) | S3, S8 |
| **Archiver** | Source of exported archive video; permits only **two simultaneous exports** — throttle to match | S1 |
| **Active Directory role** | Needed for Windows/AD logon via the Platform SDK. **AD users cannot sign in to the Web SDK.** Several `ConnectionStateCode` values (`AuthenticationAgentImportFailure`, `NoAuthenticationAgent`, `SpecifyDomain`, `UserAndSupervisorOnDifferentDomains`) are AD-specific | S1 |
| **Unit Assistant role (UAR)** | Path for updating unit passwords through the SDK | S1 |
| **Licensing / GTAP** | Certificates and part numbers are validated against the license; customers reapply the license after adding your part number | S1, S11 |
