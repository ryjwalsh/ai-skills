# Unity Video Server User Guide 8.8 (bundle unity-video-server-8-8, HTML-SERVER-H Rev 3 EN20260330)
Base: https://docs.avigilon.com/bundle/unity-video-server-8-8/page/<path>

- Server = Windows service + Admin Tool. Editions Core/Standard/Enterprise (camera count, client connections, features). Installed by Software Manager. Don't install on AD/DNS servers; run Windows Update first. [overview/server.htm]
- Admin Tool: Start > Avigilon > Avigilon Unity Video Server > Admin Tool, or desktop shortcut. General tab: launch Client, view Application Logs; Settings tab: Storage, Network, Storage Management. Start Up / Shut Down buttons ("The Avigilon Unity Server is Running / Not Running"). Shutting down stops all recording. [getting-started/admin-tool.htm]
- Storage config: must Shut Down server first; Settings > Storage. Set Config Volume; Add Data Volume… (size); Set Primary Data Volume (holds index DB; can't delete, only Erase All Data); Delete Data Volume (secondary; erases that drive's video). Recommendations: Config + Data volumes on drives other than OS (C:); primary ≥500 GB; all data volumes similar capacity; primary ≥20% of total; volumes = storage channels. Erase All Data wipes recordings AND server settings; must recreate storage before start. [system-management/change-storage.htm]
- Network: Admin Tool > Settings > Network > base port (default 38880 per client guide); service ports derive from base port; change only for multiple servers behind same NAT or port conflict. RTP port range must reach clients (forward through NAT). Sync server to NTP (Unity Cloud time mismatch causes issues). [system-management/configure-server-network.htm]
- Storage Management (archive; Std/Ent): Admin Tool > Settings > Storage Management > Enable Storage Management > Archive Folder (any Windows-accessible path; shared path allowed for central archive). If service runs as specific user: grant Modify, Read & execute, Write on folder. [system-management/enable-storage-management.htm]
- Server certificate (replace self-signed): certlm.msc > Personal > Certificates > Request New Certificate (AD Enrollment Policy) > Properties: Friendly Name AccServerCert (or UnityServerCert), Subject > Alternative Name DNS = FQDN, Private Key > Make private key exportable (+ custom permissions if service account) > Enroll. Requirements: LocalMachine\Personal store, friendly name AccServerCert/UnityServerCert, exportable key, SAN = FQDN, not SHA1, CAs in Trusted Root/Intermediate stores on all servers & clients. After new cert restart "Avigilon Unity Orchestrator Service" (services.msc); log in with full hostname incl. domain. Export CAs via Certification Path > View Certificate > Details > Copy to File; import into Trusted Root / Intermediate on other machines. Disable trust of default Avigilon certs after CA-signed setup. [system-management/server-cert-management.htm]
- Server-side C2PA signing (email attachments/exports): cert with Friendly Name MediaSigningCert in certlm.msc Personal on EVERY server in cluster; Site Setup > [site] > Security > "Enable signing of MP4 and JPEG exports". [using-administrator/enable-c2pa-standards-server.htm]
- Application logs: Admin Tool > General > Application Logs > double-click error. [using-administrator/view-app-logs.htm]
- RESET ADMINISTRATOR PASSWORD (last resort — deletes ALL users/groups): Admin Tool > Shut Down (all servers in site); Settings > Storage to find Config Volume drive; delete all files in <ConfigVolume>\AvigilonConfig\Db\DirectoryShared\Users (e.g. D:\AvigilonConfig\Db\DirectoryShared\Users) on EVERY server; Start Up each; log in administrator / blank password. Avoid by keeping a second admin-equivalent user. [additional-support/reset-admin-password.htm]

# Licensing Portal User Guide (bundle licensing-portal, Rev 1 EN20260706)
Base: https://docs.avigilon.com/bundle/licensing-portal/page/<path>
- Portal: licensing.avigilon.com (email/password; clear cache if login fails). Accounts per company; partners request customer accounts via Avigilon Order Management (legal name, address, technical contact name/email, role Customer Administrator). [license-server/initial-setup/logging-in.htm]
- List Entitlements: Activation ID (product key), Entitlement ID (sales order), Sold to, Product (part number), Version, Available quantity, Expiration. Unactivated if Available = Total. Export > Export Selected Items (CSV for installers). [license-server/licenses/viewing-licenses.htm]
- Devices page: activated licenses (fulfillments) per device (site Device ID). [license-server/licenses/viewing-activated-licenses.htm]
- Transfer channels (admin): List Entitlements > check license > Transfer > Transfer Amount > Target Account > same IDs? No/Yes > generate IDs? > Transfer. ACC 4/5/6 licenses must transfer whole. Add channels to existing license: transfer from bulk license of same Product, select Yes and pick target license. Smart Assurance Plan & bundle licenses can't be transferred+merged. [license-server/licenses/transferring-licenses.htm]
- Users: List accounts > Actions > Create a user (email not editable later; roles Regular / Administrator / Partner). List users / List related accounts / List related users (partners). Forgot password on login page (may need account admin). [license-server/users/creating-users.htm]
- Glossary: Device ID = unique identity of an Avigilon site; Entitlement = right to get a license; Fulfillment = activated license. Offline activation via activate.avigilon.com (see client guide).
