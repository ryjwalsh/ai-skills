## Getting started / access
- Discover site: Site Login tab > Find Site > IP/hostname + Base Port (default 38880; change in Unity Video Admin Tool). If not found: network, firewall, server service running. [getting-started/discovering-sites.htm]
- Sign in: New Task menu > Site Login > pick site (+Find a site) > credentials or "Use Windows credentials". First login: username `administrator`, blank password, forced password change. 2FA = TOTP app. Windows creds failing => Kerberos env. [getting-started/start-up-client.htm]
- Cloud sign in: Sign in with Cloud > region > cloud creds > site > Connect. [getting-started/sign-in-client-using-cloud-login.htm]
- Sign out: top-right (profile) > Log Out. Forgotten admin password reset requires Avigilon Tech Support and affects every server in site — keep a backup admin user. [getting-started/change-password.htm]
- Interface: System Explorer (search by name, location, Logical ID, IP, serial), View area, Image panels, Toolbar, Tabs, New Task menu (system settings), Application menu (top-right: profile, Client Settings), System Messages (Red error/Yellow warning/Green info). [getting-started/navigate-client.htm]
- Language: top-right > Client Settings > Language dropdown (Windows Default) > OK > restart client. [customizing/change-language.htm]
- Theme: top-right > Client Settings > Display tab > theme. [customizing/change-theme.htm]
- System Explorer layout (folders, order, hide): New Task > Site Setup > [site name] > Site View Editor. Folders only visible in View tab. [customizing/edit-system-explorer.htm]
- Video display settings: Client Settings > Display: Deinterlaced, Display Logical IDs, Device Preview, Display Quality, Display Adjustment (contrast/brightness; per-panel via right-click > Display Adjustments…). Client-side only. [customizing/adjust-display-settings.htm]
- Overlays: Client Settings > Overlays: Device Name, Device Location, Playback Timestamp, Live Timestamp, Record Indicator (needed for manual recording), Motion Activity, Video Analytics Activity, Text Inputs (POS), User Name Watermark, Live Video Analytics Activity (Off/Motion Only/All), License Plate (Enterprise), PTZ Field of View. [customizing/video-overlay.htm]
- Timestamp zone: Client Settings > Overlays > Timestamp Zone: Show device time / Show local time. [customizing/timestamps.htm]
- Joysticks: Client Settings > Joystick; Scan for Joysticks…; Avigilon Pro Joystick Keyboard "Enable left-hand mode"; standard DirectX USB joystick button mapping. [customizing/joysticks.htm]
- Share discovered sites with all Windows users on the workstation: Client Settings > Site Networking > Share Sites (shared sites get default WAN (Secured)). [getting-started/sharing-discovering-sites.htm]
- Disable automatic site discovery (stops unencrypted discovery broadcast): Client Settings > Security > "Disable automatic site discovery". [getting-started/disabling-auto-site-discovery.htm]
- Connection type LAN/WAN: Client Settings > Site Networking > click site > Connection Type: WAN (Secured). KEY TROUBLESHOOTING: ports 51000-55000 UDP must be open between viewing stations and servers; if closed, LIVE video is black but recorded plays — set WAN (Secured). [getting-started/setting-connection-type.htm]

## Device Management (Site Setup)
- Discover device: New Task > Site Setup > Connect/Disconnect Devices > Find Device… (Search From Server, Search Type IP Address / IP Address Range, Device Type: Avigilon / ONVIF / Avigilon Legacy (JPEG2000, port 55080) / brand; Control Port default 443; "Apply credentials to all uninitialized devices"). 3rd-party ONVIF: update firmware, set date/time, sync NTP — Unity Server has built-in NTP on UDP 38884. Forgotten device creds => factory reset. [system-management/discover-device.htm]
- Connect device: Site Setup > Connect/Disconnect Devices > Discovered Devices > select (filter "Uninitialized devices") > Connect… > Connect to: server; Device Type (3rd party); Connection Type: Primary (failover = secondary/tertiary); Device Control: Secure/Unsecure; Network Type: LAN/WAN (WAN if ICMP blocked); IP Address Type preference (Link-Local > Unique Local > Embedded IPv4 > Global Unicast); template; admin credentials (use device administrator user); location in System Explorer. [system-management/connect-device.htm]
- Device network settings: Site Setup > [device] > Network: Obtain automatically (DHCP then Zeroconf 169.254.x.x) / static IP+mask+gateway; Control Port; Enable Multicast (needed for redundant recording to multiple servers) IP/TTL/Base Port. Rialto restarts. [system-management/device-network-settings.htm]
- IPv6 (Avigilon devices only, server IPv6 enabled): Site Setup > [device] > Network > Enable IPv6, Accept Router Advertisements, DHCPv6 State Auto/Stateful/Stateless/Off, Static IPv6 Addresses, Default Gateway (only if RA disabled). [system-management/network-settings-IPv6.htm]
- Device identity: Site Setup > [device] > General: Device Name (default model), Device Location, Logical ID (unset by default), "Disable device status LEDs" (covert). [system-management/set-device-identity.htm]
- Disconnect: Site Setup > Connect/Disconnect Devices > Connected Devices > Disconnect (or drag to Discovered). Camera stays in System Explorer until recordings age out. [system-management/disconnect-device.htm]
- LAN to WAN: Connect/Disconnect Devices > select connections > Edit… > Network Type: WAN (encrypts; needed when ICMP blocked). [system-management/change-lan-to-wan.htm]
- Zoom/focus: Site Setup > [camera] > Image and Display: Continuous Focus / Manual Focus; Zoom buttons; Iris: Open (shortest DOF) then Focus buttons; Auto Focus once; HD Pro lens must be in AF mode. Apply to Devices… for same model. [customizing/zoom-focus-lens.htm]
- Dewarping (3rd-party fisheye; Avigilon fisheye auto): Site Setup > [camera] > Dewarping: Enable Dewarping, Lens Type, View Perspective Floor/Ceiling/Wall; Adjust Image overlay sliders; Restore Defaults. Perspective change can reboot & change aspect ratio — disconnect/reconnect then Restore Defaults. [customizing/dewarp-fisheye.htm]
- Image Dimensions (JPEG2000 only): Site Setup > [camera] > Image Dimensions (crop Top/Left/Width/Height). [system-management/image-dimensions.htm]
- Image and Display: Site Setup > [camera] > Image and Display: Auto Contrast Adjustment toggle (client only), Day/Night Mode Automatic/Day/Night, "Disable IR filter in Night Mode", Day/Night & Night/Day Threshold (EV) sliders, Synchronize Image Settings with All Heads, Exposure, Iris, Maximum Exposure, Maximum Gain, Color Palette (thermal: WhiteHot/BlackHot/Rainbow), Priority Image Rate/Exposure, Flicker Control 50/60 Hz, Backlight Compensation, Enable Wide Dynamic Range, Enable Adaptive IR Compensation, Enable IR LED in Night Mode / IR LED Settings, Saturation, Sharpening, Brightness, Contrast, Image Rotation 90/180/270, White Balance Automatic/Custom (Red/Blue), Enable Image Stabilization (incompatible with WDR, Dynamic Privacy Mask, Privacy Zones, Removable Privacy Zones). [system-management/image-display-settings.htm]
- Day/Night from image panel: lower-right Set Day/Night Mode button (applies to all users & recorded). [customizing/set-day-night-mode.htm]
- IR LEDs: Image and Display > Day/Night Mode Night or Automatic > IR LED Settings > Enable all LEDs or individual, intensity 0-100 > Apply. Set 0 to stop reflections off walls/eaves. [customizing/configure-ir-leds.htm]
- Digital defog: image panel lower-right defog button + slider/auto. [customizing/use-digital-defog.htm]
- Pixel measuring tool (analytics/LPR): Image and Display > toolbar pixel tool > purple overlay shows pixels at analytics resolution. Not for fisheye or analytics-appliance cameras. [customizing/measuring-pixels.htm]
- Compression and Image Rate: Site Setup > [camera] > Compression and Image Rate: Total Camera Bandwidth estimate; Format; Stream Mode Single (HDSM 2.0) / Dual (use for 3rd-party integrations); Image Rate (ips; H.264/265 must divide max rate); Image Quality 1 (best) – default 6; Max Bit Rate kbps; Resolution (thermal keep default); Keyframe Interval (≈1 keyframe/s, e.g. 20 at 20 ips) + Keyframe Period; Enable Low Bandwidth Stream / Enable secondary stream. [system-management/compression-image-rate.htm]
- HDSM SmartCodec: Compression and Image Rate > Enable HDSM SmartCodec > Bandwidth Reduction Low/Medium/High/Custom; On Motion: Background Image Quality; On Idle Scene: Post-Motion Delay s, Image Rate, Image Quality, Max Bit Rate, Keyframe Interval. Uses motion detection area to decide idle. [system-management/enable-hdsm.htm]
- Idle Scene Mode: Compression and Image Rate > Enable Idle Scene Mode > Post-Motion Delay, Image Rate, Image Quality, Max Bit Rate, Keyframe Interval. [system-management/enable-idle-scene-mode.htm]
- Recording Profile (dual-stream): Compression and Image Rate > Enable Low Bandwidth Stream > Recording Profile: Record High Bandwidth / Record Low Bandwidth (3rd-party only), HDSM Auto, HDSM Auto [Low Resolution] (legacy), HDSM Flexible, Manual. Adjust High stream first. Must match on every server connection incl. failover or settings overwrite each other. [system-management/adjust-video-streams.htm]
- Microphone: Site Setup > [device] > Microphone: Microphone Inputs; mode Analytics events only (H6A/H6XP) / Live / Live and Recording / Disabled; Gain dB; Listen; Link to Camera(s). Internal mic physical switch must be ON. Configure on each failover connection. [system-management/configure-microphone.htm]
- Speakers: Site Setup > [device] > Speakers: Speaker Off toggle, Record checkbox, Volume, Link to Camera(s), Microphone Level test. [system-management/configure-speakers.htm]
- PTZ (RS-485 analog PTZ on Avigilon cams/encoders): Site Setup > [camera] > General > Enable PTZ controls > Protocol (Pelco D/P, AD Sensormatic, AXSYS, Ernitec, Honeywell Diamond, Kalatel, TEB, Videotec MACRO/Legacy, Vicon, JVC), Dip Switch Address, Baud Rate, Parity. 3rd-party PTZ not configurable here. [system-management/configure-ptz.htm]
- Digital Inputs (Std/Ent): Site Setup > [device] > Digital Inputs and Outputs > Digital Inputs: Name, Recording Duration Follow event / Maximum time, Pre/Post-Event Record Time, Circuit State, Link to Camera(s). [system-management/configure-digital-inputs.htm]
- Digital Outputs: same dialog > Digital Outputs: Name, Circuit State, Output Mode Hold / Pulse (Repeat Count, Total Duration, Pulse Duration), Link to Camera(s). [system-management/configure-digital-outputs.htm]
- APD (Presence Detector, radar up to 9 m/30 ft, no camera channel): Site Setup > [APD] > settings: Range slider, Dwell Time, Sensitivity. Events: Presence Detected / Ended / Dwell Time Exceeded / Dwell Ended. [system-management/avigilon-presence-detector.htm]

- Camera operating priority: Site Setup > [camera] > General > Mode: High Framerate / Full Feature / No Video Analytics (use when AIA2/AI NVR does server analytics). [system-management/change-camera-mode.htm]
- FIPS on device: Site Setup > [device] > Network > Encryption Mode: FIPS 140-2 Level 1, FIPS 140-3 Level 1, NXP TPM (both need CAM-FIPS license), CRYPTR FIPS 140-2 Level 3 (card, license included; new CSR/cert via Camera Configuration Tool). May reboot. [system-management/enable-fips-cartography.htm]

## Device maintenance
- Camera Templates (needs Set up sites privilege): Site Setup > [site] > Camera Templates > + Add camera template > name > settings > Save. Edit template settings; Template assignment tab: Apply to one camera / Apply to all selected / Apply all; status icons In Sync / differs / unsupported / error / pending. Works for Avigilon + ONVIF-driver cameras; not applied to disconnected cameras. Assign at connect time via "Assign Camera Template". Duplicate/export/import (import never overwrites). [system-management/camera-templts-config.htm]
- Retention via templates (needs Set up recording and bandwidth privilege): Edit template settings > Retention checkbox > Max. Record Time / Min. Record Target (days). Overrides & unlinks Recording and Bandwidth settings. Out of Sync status; sync via Template assignment > sync icon / Apply all. [system-management/camera-templts-set-retention.htm]
- Min retention alert rule: Rules > event "Minimum retention not met on server" > actions Display on-screen message + Send email. Also triggers when camera disconnected. [system-management/camera-templts-retention-alerts.htm]
- Auto camera firmware offers: Site Setup > [server] > (server general) > "Automatically update cameras" checkbox (default on). [system-management/firmware-updates-enable-disable.htm]
- Upgrade camera firmware: via Software Manager (download single camera firmware); Site Health > Devices > Hardware column shows firmware/serial + upgrade-needed icon. Video pauses during upgrade. [system-management/upgrade-camera-firmware.htm]
- ONVIF health check: LAN uses PING (unless DisablePing config) ; WAN uses ONVIF-based check. Disable: Connect/Disconnect Devices > [ONVIF device] Connect… or Edit > Advanced > "Disable Onvif health check". [system-management/disable-onvif-health-check.htm]
- Failover: requires Enterprise Edition on all servers, merged multi-server site, cameras reachable by all servers, failover licenses per camera. Connect/Disconnect Devices > [device] > Edit… > Change on server > Connection Type Primary/Secondary/Tertiary + License Priority 1 (highest) – 5. Server-based (not triggered by single camera offline). Enable mic/speakers on secondary/tertiary. [system-management/failover-connections.htm]
- Reboot device (Avigilon only): Site Setup > [device] > General > Reboot Device…. [system-management/reboot-device.htm]
- Replace device: original must show Not Present (unplug, wait). Replacement: same username/password, temp IP, similar capabilities. Connect/Disconnect Devices > Discovered Devices > select replacement > Replace > pick Not Present device > OK > Yes. Transfers recorded video, saved views, rules, alarms, events, bookmarks, maps; reconfigure compression, motion, analytics, ACM door links, POS, LPR. Repeat per failover connection. If original comes back online: disconnect both, factory reset each, reconnect. Save old settings/site health report first. [system-management/replace-device.htm]
- Profile G recovery (ONVIF SD card): Site Setup > [server] > Recovery Configuration: Maximum streams to recover (≤200), Limit recovery rate. Gaps >5 s healed (>60 s if "Record only when server connection is interrupted"). Camera time must be synced. [system-management/recover-video-profile-g.htm]

## Analytics
- Server analytics enable/disable: Site Setup > [server] > Server Analytics > feature tabs (Appearance Search & No Face Mask need Enterprise; Face Recognition & Firearm Detection separate licenses; Firearm only on AI NVR not AI Appliance) > select cameras; capacity bars. Retention of appearance signatures: Identity and Privacy Settings. [system-management/enabling-analytics.htm]

- Camera analytics settings: Site Setup > [camera] > Settings (analytics): Camera Type (Day and Night/Color/Black and White/Thermal); Analytics Scene Mode: Outdoor, Large Indoor Area, Indoor Overhead*, Outdoor High Sensitivity*, Long Range Night* (H4A only), Indoor Close-up (modular only) (*not H5A); H5A Fisheye analytics only ceiling-mounted with View Perspective Ceiling; Enable Noise Filter; Display Classified Objects; Enable Tampering Detection + Sensitivity 1-10 + Trigger Delay 2-30 s (default 8); Enable Self Learning. Bulk via Camera Configuration Tool. [system-management/configure-camera-analytics.htm]
- Video Analytics Mode: Site Setup > [device] > General > Video Analytics Mode: Classified Object / Unusual Motion / None. Can run camera UMD + server Classified Object together. [system-management/video-analytics-mode-enable.htm]
- Unusual Motion (pixel-based, 2-week learning) vs Unusual Activity (classified objects, Next-Gen analytics, 1-week learning). [system-management/unusual-motion-activity.htm]
- Tampering off: Site Setup > [camera] > Settings > clear Enable Tampering Detection. [system-management/disable-tampering-detection.htm]
- Rialto appliance: Site Setup > [appliance] > channel > Linked Camera (same server; >2 MP uses secondary stream). No Appearance Search. [system-management/configure-rialto-appliances.htm]
- Self-learning: progress bar in camera Settings (0-33 gathering, 34-66 adjusting, 67-100 accurate; ~200 high-confidence full-body detections). Disable when no people/vehicles expected, objects at different heights, Indoor Overhead. Reset (Settings > under progress bar > Reset > Apply) after camera moved/zoom/focus/PTZ home change. Suspend/Resume there too (suspend <100% clears data). [system-management/self-learning.htm]
- Teach By Example: assign markers via New Task > Motion > Classified Object Motion search > play result > click bounding box > True/False; ≥30 true + ≥30 false (max 200 each); apply at Site Setup > [camera] > Teach By Example > Apply; Restore to Factory Default after camera moved. Status: Settings > Self Learning > Teach Markers Applied. [system-management/teach-by-example.htm]
- Motion Detection: Site Setup > [camera] > Motion Detection: tabs Classified Object Motion Detection (green ROI, exclusion areas, Object Types + vehicle subtypes, Sensitivity, Threshold Time (+1 s implicit), Pre/Post-Motion Record Time; PTZ Home only; H5A fisheye center deadzone) and Pixel Motion Detection (draw/exclude/select all/clear; Sensitivity, Threshold w/ Motion indicator, Pre/Post record). Recommend Pixel Motion for recording triggers in high-security (classified motion only records pre/post window). [customizing/set-classified-motion-detection.htm] [customizing/set-pixel-motion-detection.htm]
- Analytic Events: Site Setup > [camera] > Analytic Events > Add: name (unique site-wide), Enabled, Activity, Object Types (+vehicle subtypes), PTZ Preset (Home default), ROI + exclusion; Occupancy Area name, Sensitivity (default 8), Number of Objects, Threshold Time, Timeout (default 60 min), Prohibited Direction. Temperature activities: Timeout 2-15 s (default 8), Lower/Elevated Temperature Threshold. Cannot change activity type of existing event — create new. Renaming breaks linked rules/alarms. [customizing/configure-analytic-events.htm]
- Activities: Autotrack object in area; Objects in area; Object loitering; Objects crossing beam (direction toggle/bidirectional); Object appears or enters area (event per object — noisy); Object not present in area; Objects enter area; Objects leave area; Object stops in area (tracked ≤15 min); Direction violated (within 22°); Enter/Exit occupancy area; Objects too close. Thermal: Object with lower/elevated/expected temperature (H4 Thermal ETD); Sudden temperature change, Temperature crossing (H5T). [customizing/analytic-event-descriptions.htm]
- Rules: Site Setup > [site] > Rules > Add > Select Event(s) > Next > Select Action(s) > Next > Select Condition(s) > Next > name (unique), description, schedule (default Always), "Rule is enabled" > Finish. Blue links refine. Edit: select rule (search box) > Edit. Schedules: recurrences with Start/End (End < Start spans 2 days), Daily/Weekly/Monthly/Yearly. [customizing/add-rules.htm]
- HTTP web request action: Rules > Add > event > Next > User Notification Actions > "Send web request" > click web request link > Web Request Setup: method (POST…), URL, up to 20 headers (Content-Type case-sensitive; default application/json; no */*; Content-Length must match body), Body > Save. Endpoint response visible in Site Logs. [customizing/rules-action-generic-web-request.htm]
- Alarms: Site Setup > [site] > Alarms > Add > trigger source: Motion Detection, Video Analytics Event (all events on camera), Firearm Detection, Audio Analytics Event, Digital Input Activation, License Plate Watch List Match, POS Transaction Exception, Device Error, System Error, External Software Event, Face Watch List Match > devices > Pre-Alarm Record Time + Recording Duration + linked devices > users/groups notified (wait time) > acknowledge actions > name, priority, schedule > Finish. [customizing/managing-alarms.htm]
- Alarm for specific analytic events: create alarm with trigger External Software Event; then rule "Video analytics event started" (select events) > action "Trigger an alarm" > pick that alarm. Same event name across cameras triggers for all. [customizing/add-analytic-alarms.htm]
- Rule events reference: Server events (startup/shutdown/terminated unexpectedly, low on resources, install error, license expires soon/expired, database error, data volume failed/recovered/size reduced, data write error, data upgrade/recovery started/completed/failed, bookmark save failed, network connection found/lost, email send error, server hardware event, archiving started/completed/interrupted, server connection lost, analytics server queue full, analytics server connection lost, LPR Add-on restarted/terminated, Active Directory connection failed, cloud analytics connection lost/restored, Unity AI service connection lost, minimum retention not met on server). Device events (connection created/removed, to/from standby server, connection failed, device failed (>5 min), connection restored, network packet loss unacceptable/acceptable, motion started/ended, classified object motion started/ended, video analytics event started/ended, Unusual Motion/Activity started/ended, tampering detected, audio analytics started/ended, crowd detection started/ended, Z-Wave event started/ended …).
