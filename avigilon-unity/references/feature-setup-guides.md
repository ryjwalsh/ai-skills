# Feature setup guides (Unity Video 8.8)

## Media Gateway (bundle unity-video-media-gateway-8-8, Rev 3 EN20260330)
- RTSP proxy transcoding HDSM 2.0 mosaic streams for 3rd-party players. Install via Software Manager (Avigilon Unity Media Gateway app); Windows service "Avigilon Unity Media Gateway Service" (start if stopped). [system-management/media-gateway-installation.htm]
- Config: C:\Program Files\Avigilon\Avigilon Unity Media Gateway\config.json — port (8554, restart), endpoints ["127.0.0.1:38881"] (Unity server HTTPS daemon port: Admin Tool > Settings > Network > HTTPS Port/HTTPS (Daemon); restart), sessionTimeout 60 s, useFfmpegTranscoding true, encodePasswords true (token = Base64 of password), stream_types {name:{min_fps,size}}, default {size:{width,height}} (REQUIRED or service won't start). [system-management/media-gateway-configuration.htm]
- URL: rtsp://[user]:[token]@[IP]:8554/media/[CameraId]?size=W,H&burnin=true&t=live|ISO8601&t_max=ISO8601&min_fps=N or ?stream_type=name (exclusive with size/min_fps). Token: URL-encoded Base64(password) (PowerShell [Convert]::ToBase64String + [System.Uri]::EscapeDataString). CameraId: WEP id via POST http://<WEP>:8443/mt/api/rest/v1/login then GET /mt/api/rest/v1/cameras?verbosity=LOW; or TQ format PrimaryDeviceId+DataStoreId+ServerId+ClusterId. t without tz = gateway local time. Performance (Xeon E-2286M): 1080p30 ≈3 streams, 720p30 ≈5, 480p30 ≈15. [system-management/media-gateway-rtsp-url.htm]

## Federated Authentication (bundle unity-video-federated-authentication-8-8, Rev 1 EN20260812)
- UCS federation with Entra ID (Azure AD) or Okta (not Google). Unity 8: 1) provision federation 2) IdP app for group import 3) import groups (Privilege Management > User groups > +New user group > Import from External Directory) 4) add group to policy; manual Sync group after IdP changes (sync failure ⇒ expired secret/key). ACC 7: add users manually (UCS Organization Management > Users > Add user, or ACC Users and Groups > Add User with email + Connect checkbox; invite link 24 h; default Viewer). Local users with matching email overwritten; Primary Administrator keeps Organization Administrator group. [overview/federated-authentication.htm]
- Azure federation app: App registrations > New registration, Accounts in this organizational directory only, Redirect URI Web https://acsb2cprod.b2clogin.com/acsb2cprod.onmicrosoft.com/oauth2/authresp; Authentication > Implicit grant: Access Tokens + ID Tokens; client secret; API permissions Microsoft Graph User.Read (Delegated), User.Read.All (Application), profile, openid + Grant Admin Consent; Token configuration optional claims (ID): family_name, given_name, preferred_username; submit Federated Authentication Request form (Client ID, Tenant ID, secret, date/time, time zone). Group import app: separate registration, no redirect, Application permissions User.Read.All, Group.Read.All, GroupMember.Read.All + admin consent; UCS Organization Management > + Add Identity Provider. [web-client/getting-started/provision-fed-azure.htm]
- Okta federation: Create App Integration OIDC Web; grants Authorization Code, Confidential, Implicit (Hybrid); Sign-in Redirect URI same b2clogin URL; API scope okta.users.read.self; custom groups claim on default Authorization Server (scope "groups", claim Groups regex .*), access_token scope, access policy with groups/openid/profile/email/phone; submit form (domain, Client ID/Secret/expiry, Okta Domain). Group import: Web app; scopes okta.users.read + okta.groups.read; Public key/Private key auth (JWKS, record private key); Read-only Administrator admin role; clear DPoP. [web-client/getting-started/provision-fed-okta.htm]
- UCS roles: Administrator (all), Manager, Responder, Viewer. Primary Administrator changed in org settings General tab. Support user support@avigilon.com (grant site access for Avigilon Support; creates Cloud Administrator group member on ACC servers). Service-package System Administrator users (dealers/monitoring) live in Cloud Administrator group. [web-client/users/legacy-users/roles.htm]

## License Plate Recognition (bundle unity-video-license-plate-recognition-8-8, Rev 1 EN20260513)
- Requirements: Client + Server latest; "Avigilon Unity LPR Add-on" (LPR v2) on every server (AI NVRs don't need it); lower Primary Data Volume % for headroom. Licenses: UNITY8-LPR per lane; VME needs Unity8-ENT. Privileges: Set up LPR settings (channels+watchlists), Set up LPR watch lists (watchlists only), Set up VehicleManagerEnterprise integration, Licensed search for identifying features, Export images, alarm/rule privileges. [customizing/lpr-sys-reqs.htm]
- Camera clarity: image not rotated; keyframe period ≤1-2 s (keyframe interval < image rate); ≥10 fps (speed table: 0-20 mph 5/10 ips; 20-30 10/15; 30-40 15/24; 40-60 24/not recommended); plate ≥75 px (US) / 90 px (EU), >250 px no gain; Maximum Exposure 1/8 s stop-and-go, 1/1000 s moving, 1/2000 s fast; Gain 6 dB (H4-LPC ≤24 dB; >50 mph gain 12 dB + 1/2000 s); disable WDR, auto focus (manual), HDSM SmartCodec, Idle Scene Mode; Image Quality 4. [customizing/lpr-setup-checklist.htm]
- Enable: Site Setup > [server] > Server Analytics > LPR tab (missing tab ⇒ license not activated) > cameras. Not for L6A cameras (on-board). [system-management/lpr-activate-lpr.htm]
- Lanes: Site Setup > [server] > License Plate Recognition > lane: Name (unique), Camera (one camera can serve multiple lanes), License Plate Configuration (region), Pre/Post-Event Record Time, Minimum Confidence %, Max Image Analysis Rate, Enable this lane, green ROI across lane (red = too large). Linux appliances (AI NVR/ENVR2 Plus): disable HDSM 2.0 → camera Compression and Image Rate > Stream Mode Dual Mode + Recording Profile HDSM Flexible > restart appliance. AI NVR LPR Performance Mode: System Explorer > device > Management Interface > Server panel > General > LPR Performance Mode toggle (disables Face Recognition/Mask; Value also loses Classified Object Detection). [customizing/set-license-plate-recognition.htm]
- Watch lists: Site Setup > [site] > License Plate Watch List > Add (name, description; Add plate + minimum confidence; Import CSV with Minimum Confidence column; up to 2 million plates). Export: Edit > Export (CSV). Alarm: Alarms > Add > License Plate Watch List Match. Rule: Rules > events "License plate watch list match" (Any of the following devices / watch lists) or "License plate detection started" (specific plates) > action Trigger an alarm. Overlay: Client Settings > Overlays > License Plate. Retention: Identity and Privacy Data > LPR days (video retention shorter wins). [customizing/lpr-add-watch-lists.htm]
- VME (L6A + LPR2 servers): Site Setup > [site] > VehicleManager Enterprise: System URL, Agency/Site, Username, Password > Connect (VME user needs CarDetector Admin/Operator). Ports: outbound ephemeral 41952-65535 → VME 443. Group privilege "Set up VehicleManagerEnterprise integration". [customizing/vehicle-manager-enterprise-connect.htm]
- Search: New Task > License Plates > cameras, date range, partial plate + Match %; L6A "Show additional information" (make/model/color). Match pop-up: View this Event / Delete / Clear All. Export event: search result > Export this event > Export tab. [using/searching-license-plates.htm]
- LPR troubleshooting FAQ: camera not showing (power, cable, ping, same segment); false reads (tighten ROI, lower sensitivity, stable mount); no events (LPR enabled on camera, rules, firmware); blurry (focus/iris, angle, lighting, shutter, IR); intermittent disconnect (cable, bandwidth, IP conflict, firmware); after upgrade → update camera firmware; watch list menu missing → "Set up LPR watch lists" privilege (can't grant what you lack; legacy "Set up LPR settings" also unlocks watchlists; re-login to refresh); merged sites combine permissions additively. [customizing/lpr-troubleshoot.htm]

## Face Recognition (bundle unity-video-face-recognition-8-8, Rev 2 EN20260330)
- Needs Face license + Appearance Search enabled on same cameras; AI NVR or NVR with Unity Analytics Service. Best cameras H5A/H6A/H6SL (not H5A Fisheye; H4A 2 MP front-facing only). Tilt ≤30°, mount ≤2.8 m; pixels on face: High 80; Medium 50 (≤6 MP) / 60 (8 MP); Low 40 (≤5 MP). [customizing/camera-placement.htm]
- Enable: Site Setup > [server] > Server Analytics > Appearance Search tab (cameras) AND Face Recognition tab (same cameras; tab missing = no license). [system-management/enabling-face-recognition-analytics.htm]
- Lists (privilege Set up face recognition lists): Site Setup > [site] > Face Recognition Lists > Add Face Recognition List > List Type Face Watch List (Default Minimum Match Confidence Very Low–High, Medium default; Alarms toggle) or Unknown Face Exclusion List (Default Sensitivity; Camera selection; not supported with ENVR2/AIA2/AIA2X) ; Default Profile Expiry. Add Profiles (passport-style, ≥60 px face width, 100 recommended; ≤5000 profiles per site; status Pending/Rejected — check Analytics Service on Site Health; quality Good/Average/Poor). From video: image panel icon > drag box > Short/Long Description > list. Profile edit: Minimum Match Confidence override, Change… expiry, Move…. Export list to another site via Backup Settings / Restore Settings > Use custom settings > Face Recognition Lists only. [customizing/add-face-list.htm]
- Rule: Rules > Device Events "Face watch list match started" / "Unknown face detected" > any device / any watch list > actions Display on-screen message, Focus of Attention, Trigger an alarm. Alarm: Alarms > Add > Face Watch List Match > list > devices > recipients > name/priority/schedule (unknown-face alarms not supported). Focus of Attention settings: Face Watch List Match / Unknown Face. Retention: Identity and Privacy Data > Face Recognition events days. Search: New Task > Events > Face Watch List Match / Unknown Face. [customizing/configure-face-recognition-rule.htm]

## Halo 4 Smart Sensors (bundle unity-video-halo-iot-sensors-8-8, Rev 1 EN20260504)
- Needs Standard/Enterprise license, 8.6+; physical mic switch on Halo ON. New sensor has no credentials — Client prompts to create admin user. Connect: Site Setup > Connect/Disconnect Devices > Find Device > Device Type ONVIF > IP/user/pass > Connect. [customizing/halo4-connect-2-halo-device.htm]
- Link cameras: Site Setup > [Halo] > link icon > cameras + "Include Halo device in rule actions". 2-way audio: Microphone button > check Halo; Speaker button > Speaker On + Record. Events: Site Setup > [Halo] > events icon > Load presets (Vape, Smoking, Masking, THC — can't be manually created) or Add custom (Data Source e.g. Relative Humidity). Categories: Motion; Tamper (X/Y/Z orientation, Move); Audio Analytics (Keyword 1-3); Environmental (Temp, RH, Lux, TVOC, CO2, PM1/2.5/10, Ammonia, NO2, CO, Pressure, AQI…, People count). [customizing/halo4-config-events.htm]
- Rule: events "Environmental event started/ended" > any environmental event > actions Display on-screen message, Trigger Device LED (color/pattern/duration), Start live streaming. Alarm: trigger source = event type (tamper → Device Error). Dashboard: drag Halo into image panel → live Sensor Dashboard; talkdown via mic/speaker icons. Search: Events > Environmental Events (needs linked camera recording); FoA settings Environmental Events / Audio Analytic Detection. [customizing/halo4-setting-rule.htm]

## Z-Wave IoT Sensors (bundle unity-video-z-wave-iot-sensors-8-8, Rev 2 EN20260417)

Alarm: Alarms > Add > Z-Wave Event; per-camera-group unique alarm via External Software Event + rule "Trigger an alarm". Overlay: Client Settings > Overlays > Z-Wave Hub; temperature unit Client Settings > General; per-sensor params right-click camera > Setup > Z-Wave Hub > Sensor Overlay. Search: Events > Z-Wave Events; FoA Settings > Z-Wave Events (yellow; CO red). [customizing/z-wave-rule.htm]

## Visual Alerts (bundle unity-video-visual-alerts-8-8, Rev 4 EN20260702)
- Generative AI (VLM) on AI Appliance 2X (VMA-AIA2X) on-prem; Unity 8.8.0.xx; Enterprise license (no extra). AIA2X WebUI AI Mode "AdaptAI + GenAI" or "GenAI" (restarts; reduces AdaptAI channels); cluster AIA2X with NVR (multi-server site); ONE AIA2X per site. Cameras ≥2 MP, keyframe ≤3 s (1 s rec.); Avigilon cams: Compression and Image Rate > Stream Mode Dual Mode, Recording Profile HDSM Flexible, Low Bandwidth Stream enabled, secondary ≥1920x1080. Enable: Site Setup > AI Appliance > Server Analytics > Visual Alerts tab > cameras. [getting-started/visual-alerts-configure-cameras.htm]
- Create: Setup > Site > Visual Alerts > New Alert > prompt (omit "Alert me when"; templates) > summary/Update Prompt > Change Camera (pick specific cameras) > Create (active within 1 min). Analysis interval 5-60 s per frame — describe persistent states, be specific, relational location, avoid negations; PPF: object 25, details 75, interaction 50, environmental 50. Guardrails reject impossible/toxic/malicious. Manage: enable/disable, Edit, Delete. View: FoA settings > Visual Alerts; Events search > Visual Alerts. Rule: "Visual Alert triggered" > any/specific > actions. Troubleshoot: Site Health AI appliance Connected; "Unavailable Notice" on page = appliance unreachable/misconfigured; AI Mode; AI compute load meter (New Alert disabled when high). Recovery: disable rules > restart Unity AI service in appliance WebUI > wait 1-2 min > re-enable. [using/visual-alerts-troubleshooting.htm]

## Occupancy Counting (bundle unity-video-occupancy-counting-8-8, Rev 1 EN20260330)
- Per camera with entrance/exit: Site Setup > [camera] > Analytic Events > Add: Activity "Enter occupancy area" (Occupancy Area name shared across cameras; Object Types Person/Vehicle; sensitivity; timeout; draw green tripwire line on floor + direction) and "Exit occupancy area". Dashboard in UCS/ACS (Organization Administrator policy; ACC 7: ACS Administrator/Manager); reset time in UCS site settings. Optional rule on "Video analytics event started/ended". Validate: Events search > Classified Object. Record Continuous/Motion. [customizing/configure-analytic-events-occup-counting.htm]

## Crowd Detection (bundle unity-video-crowd-detection-8-8, Rev 1 EN20260330)
- Unity 8.0+, H6A cameras. Site Setup > [camera] > Crowd Detection > events Crowd size / Unusual crowd growth / Unusual crowd size > toggle > Number of people, Threshold time (2-30 s default), Timeout, Sensitivity, ROI (changing ROI resets learning) > Apply. Unusual events may take 24 h to start. Rule: Device Events "Crowd Detection event started/ended" > any crowd detection event; FoA (crowd size teal; unusual yellow; FoA Settings > Crowd Detection). Search: Events > Crowd Detection Events. [customizing/configure-camera-crowd-detection-analytics.htm]

## Audio Analytics (bundle unity-video-audio-analytics-8-8)
- H6A/H6XP; some types licensed (Gunshot); physical mic switch ON; works even if mic disabled in Unity (on-camera processing). Detection ranges (ideal/noisy): Glass Break 15/8 m, Gun shot 100/50 m, Screaming 15/8 m, Smoke Alarm 15/8 m, Car Alarm 30/20 m, Ultrasonic Panic Alarm 40/15 m. Site Setup > [camera] > Audio Analytics > event > Enabled, Sensitivity, Timeout (default 35 s), Device Link (per head on multi-head). Rule events "Audio analytics event started/ended"; alarm Audio Analytics Event. [customizing/configure-camera-audio-analytics.htm]
