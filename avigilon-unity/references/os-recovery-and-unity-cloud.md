# Windows OS Upgrade and Recovery Guide (bundle windows-upgrade-recovery) — Avigilon NVR/workstation/HDVA hardware
Base: https://docs.avigilon.com/bundle/windows-upgrade-recovery/page/<path>

- Workflow: 1 prep (BIOS/firmware, `wmic computersystem get manufacturer` must show Avigilon) → 2 back up video/config (archive/export; Backup Site Settings .avs; relocate config C:→D:; System Bug Report; copy folders; Gateway files) → 3 bootable USB (NTFS/UEFI) or onboard recovery partition → 4 update ACC to latest release of same version → 5 back up config again + Site Health Report + deactivate licenses → 6 remove from multi-server site / site family → 7 (HD-NVR2 50 GB OS) RAID restructure → 8 install Windows from USB → 9 reinstall SAME ACC version, restore config, rejoin site, reactivate licenses → 10 update to latest ACC/Unity → 11 verify. [OS-upgrade-recovery-guide/os-workflow.htm]
- Recovery images: avigilon.com/support/technical/os-recovery (free; same OS edition as factory). OS upgrade kits (paid COA sticker) e.g. NVR4/4X/5/6-FORM-D-S22-UPG (Windows Server 2022), NVR4/5-VAL-NVR4/4X/5/6-STD-D-W11-24H2-UPG (Win11 IoT 2024), RM5/6/7/NVR4/4X/5-WKS-D-W11-24H2-UPG, AS3XL-S22-UPG. Do NOT use ACC installers from the recovery image — reinstall the currently installed ACC version/release. OS drive: keep ≥200 GB recommended; legacy max OS drive 500 GB. KB refs: 9988 (BIOS/firmware upgrade), 10085 (upgrade to ACC 7), 8555 (NIC best practices), 9804 (change server name/IP pre/post). [OS-upgrade-recovery-guide/os-sys-req.htm]
- Relocate config off C:: Admin Tool > Shut Down > Settings > Storage > check Config Volume; if C:, copy C:\AvigilonConfig to D:\AvigilonConfig (server stopped) + to USB > rename C:\AvigilonConfig-old > start server > "Use this Configuration". [OS-upgrade-recovery-guide/os-acc-server-data-relocate.htm]
- Folders to back up (server stopped, Admin Tool closed — check Task Manager): C:\ProgramData\Avigilon (hidden), D:\AvigilonConfig, D:\AvigilonData\Db (Appearance, Bookmarks, PointOfSale) → USB folder servername_accbackup_original_dd_MM_yyyy_HH_mm_ss; Gateway: C:\Program Files\Avigilon\Avigilon Control Center Gateway\cert\GatewayCertificate.pfx + Gateway.cfg. Restore = copy ProgramData\Avigilon back to C:\ (Support remote session recommended). [OS-upgrade-recovery-guide/os-backup-folders-original.htm]
- Onboard Avigilon recovery partition (newer NVR6/NVR5 etc.): Start > hold Shift + Restart (or down-arrow at boot) > Choose an option > Use another operating system > OS Recovery partition > Avigilon Recovery window > Recover (~30 min; OS drive wiped; video on separate disks kept). [OS-upgrade-recovery-guide/os-onboard-avo-recovery-partition.htm]
- Deactivate licenses first (ACC; Unity: Client > Site Setup > License Management > Deactivate, save .KEY/.TXT): disconnect cameras, disable rules (uncheck "Rule is enabled"), License Management > screenshot Activation IDs > Remove License… > Copy to Clipboard > Deactivate Now. Multi-server: remove server from site first. [OS-upgrade-recovery-guide/os-acc-client-license-activation-ids.htm]
- Boot USB: UEFI systems (NVR6, NVR5, NVR4X, NVR4-VAL) F11 > Boot Manager > One-Shot UEFI Boot Menu > USB device; HD-NVR4/HD-NVR3 F11 > One-Shot BIOS Boot Menu; HD-NVR2 F11 > BIOS menu > C:\hard_drive > USB; workstations NVR5-WKS/NVR4X-WKS/RM5-7 F12 > UEFI-BOOT; HD-NVRWS3/HD-RMWS3/4 F12 > Legacy-BOOT; VMA-AS3XL/AS3X F12 UEFI; VMA-AS3 F12; VMA-AS2 Esc; VMA-AS1-8P F5; VMA-AS1-16P/24P F2 > Boot Features > UEFI Boot Disabled > F5. Upgrading HD-NVR4 to WS2019 / any to Win10 2021: F2 > System BIOS > Boot Settings > UEFI first. Avigilon Recovery Console > Upgrade / Recover (~30 min). "Reboot and Select proper Boot device" → F12 > set Windows Boot Manager first. [OS-upgrade-recovery-guide/os-8-upgrade-windows.htm]
- Post-Windows: unique computer name (becomes default site name); Analytics Kit GPUs: run C:\Avigilon\3rdPartyInstallers\GPU Configuration Tool\GPU Configuration Tool.exe BEFORE installing Analytics Service (latest NVIDIA driver); NTP sync 2-hour poll. [OS-upgrade-recovery-guide/os-windows-setup.htm]
- Troubleshoot: NVR loops "You are about to be logged off / Windows will shut down in 1 minute" → admin cmd `shutdown /a` then call Support. Legacy Win7 (HD-NVR/HD-NVR2/HD-NVRWS/2MN/4MN-HD-RMWS): recovery DVD (ISO from Software Downloads, burn, boot optical via F2/F12; 4MN T5600 needs RAID drivers). [OS-upgrade-recovery-guide/os-troublesh-nvr-reboot-failures.htm]
- OMSA install and HD-NVR2 RAID restructure in Appendix A. [OS-upgrade-recovery-guide/os-osma.htm]

# Avigilon Unity Cloud Services (bundle unity-cloud) — cloud.avigilon.com
Base: https://docs.avigilon.com/bundle/unity-cloud/page/<path>
- Requirements: Unity Video 8.0+ or ACC 7.12+ with matching Web Endpoint Service on every server (except AI appliance); browsers Chrome 72+/Safari 12.1+/Edge 80+; ES cameras, JPEG2000, MJPEG unsupported. [system-requirements/cloud.htm]
- Register org: cloud.avigilon.com > region > Create a new organization > submit > email registration (link valid 24 h; password 8-50 chars w/ upper/lower/number/special, no "Password"). [web-client/getting-started/connecting-to-cloud.htm]
- Connect site: before — internet, all servers same version, add ALL servers to multi-server site first, NTP/time zone correct. Cloud: Organization Management > Sites tab > Add site > name/address/Primary Contact > Add > copy activation code (24 h; regenerate via icon next to Code Expired). Client: New Task > Site Setup > site > Avigilon Unity Cloud > enter code > Connect (allow 15-20 min; else disconnect and retry). Disconnect: Site Setup > site > Avigilon Unity Cloud > Disconnect > Yes (synced cloud users deleted from site). Status on Site Health page. [web-client/sites/adding-a-site.htm]
- Ports: 443 TCP HTTPS/AMQP server→cloud (required); STUN UDP 49152-65535; TURN 443 TCP/UDP + 3478 UDP; RTP 51000-55000 UDP; installers.avigilon.com 443. FIPS servers cannot connect. [web-client/getting-started/port-configuration.htm]
- Safelist FQDNs (TCP 443): us/ca/au.cloud.avigilon.com (+us always), api.<region>.cloud.avigilon.com, blue.avigilon.com, blueprod<region>01ops/data.blob.core.windows.net, blue-prod<region>01-iot-hub.azure-devices.net, ingress.cluster.prod<region>01.acs314159.com, installers.avigilon.com, acsb2cprod.b2clogin.com (IDP), WebRTC: rest.ably.io, ps.pndsn.com (*.pubnub.com/*.pndsn.com), global.stun/turn.twilio.com, <region>.geo-turn.aware.avasecurity.com (443 TCP/UDP + 3478 UDP); openstreetmap.org (Maps); 3rd-party media API TCP 1935 to 40.87.44.243. All servers in a multi-server site need access (mobile push too). [web-client/getting-started/safelisting-servers.htm]
- Remote Support access: org admin > Support button > Manage Avigilon Support Access > Accept / Terminate support. [web-client/organizations/remote-support-access-customer.htm]
- Cloud Site Update (needs Advanced System Health): System Health Dashboard > Sites > Update available icon > Details > Select version > Update > Download (one server downloads, distributes) > Install per server > Continue installation (recording stops; reboot button may appear). Site Health Report: Sites > Details > Download report (XLSX). System Bug Report: Servers > Status icon > Generate System Bug Report (up to 15 min; stay on page). [web-client/sites/updating-a-site.htm]
- Central station webhook (service providers): URI (HTTPS), unique username + password, Shared Secret Phrase (≥6 chars). [web-client/service-providers/central-station/setup-webhooks.htm]
- Troubleshooting: expired activation code → Sites tab regenerate. Expired user link → Site Setup > Users and Groups > Edit user > clear Connect > OK > re-check Connect (new email). Site connect fails "temporarily unavailable" → firewall/AV outbound, version ≥7.10 all servers, Web Endpoint installed/running/same version (see Site Health report). No cameras in web client: site connected? 410 = unsupported browser; 504 = site not talking to cloud / Web Endpoint; Authentication Failed = re-toggle Connect on user; Permission Denied = camera privileges. 401 viewing cameras = server time wrong → NTP. No System Health / Occupancy icon = need Administrator/Manager role. Skewed UI → Ctrl+F5. Forgot cloud password → reset via company IdP/IT (federated). [web-client/troubleshooting/other-issues.htm]
- Privilege Management (UCS Unity orgs): Users / Groups (import from IdP) / Roles / Policies (group + role + resources); restrict remote streaming per policy. [web-client/privilege-management/managing-privileges-and-access.htm]
