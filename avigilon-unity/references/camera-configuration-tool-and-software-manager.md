# Camera Configuration Tool (CCT) 2.18 User Guide (bundle camera-configuration-tool-2-18; guide text says CCT 2.8 core)
Base: https://docs.avigilon.com/bundle/camera-configuration-tool-2-18/page/<path>

- Purpose: discover, claim, bulk-configure cameras (Avigilon + Pelco); install on PC in same subnet (avigilon.com/software-downloads > CCT .exe). Sends discovery broadcast every minute; force via top-right broadcast icon. [CCT-FindCameras.htm]
- Login prompt on launch: single User Name/Password for all; checkbox "Use the factory default credentials if the above credentials fail" (admin/admin or administrator/<blank>); factory-default cameras with no credentials are NOT logged in — set via Admin Users tab. Failed logins → Connection Credentials tab. [CCT-FindCameras.htm]
- Layout: setting tabs left, task menu right, camera list, implementation area bottom-right (count + pending changes; Apply / Discard). Edited cells yellow; rejected rows red; Failed filter. Column header edit icon = apply to all listed cameras. Filter via column funnel; active filters listed bottom. [CCT-EditCameras.htm]
- Status icons: logged in; logged in with default creds (change!); factory default no creds; trying; failed login; lost comms; HTTPS trusted / self-signed / not trusted / invalid cert. [CCT-CameraStatus.htm]
- Tabs & columns: common (Web UI link, Live video, status, Model, Name, Head #). General: Location, Disable Camera Status LEDs, dates discovered, Serial, Manufacturer, Firmware Version, Date, Enable PTZ, PTZ Name, Enable Metadata. Network: Enable DHCP, IP, Subnet, Gateway, Hostname, NTP Server Mode (DHCP/Manual), NTP Server, MAC, Enable HTTP, HTTP/HTTPS Port. Multicast: video/audio/metadata IP, Port (even), TTL per profile (Primary/Secondary/Tertiary selector bottom-left; disable = 0.0.0.0 port 0; unique per profile/head; starts on first client). TLS: Download CSR, cert Subject/Issuer/Expiry/Type/Signature Algorithm, Manage Certificates, Certificates, Encryption Mode. Image Settings: Encoding, Flicker Control, EIS, Enable WDR, Image Rate, Quality, Max Bitrate, Resolution, Keyframe Interval, Camera Heads, Camera Mode (Full Feature/High Frame Rate/Dynamic Privacy Masks/No Video Analytics — reboot). Admin Users: Admin User Name/Password, Secondary Admin User Name/Password (backup admin; Pelco requires non-empty password). Analytics: Camera Type, Analytics Scene Mode, Enable Noise Filter, Enable Tamper, Tamper Sensitivity 1-10, Tamper Trigger Delay 2-30 (default 8), Enable Self Learning, Reset Self Learning, Video Analytics Mode (Classified Object / Unusual Motion Detection / Tamper Only), Analytic Events > Configure, Crowd Detection > Configure, Enable ONVIF Analytics Metadata (Profile M). All Settings tab. Connection Credentials tab. Firmware Update tab: Firmware Version, Available Firmware Version, Upgrade, Downgrade. [CCT-SettingTabs.htm]
- Static IPs (Network tab): column header edit > Start IP Address + Subnet Mask + Default Gateway applies a range to listed cameras (DHCP auto-disabled); or double-click per camera. Only use reachable subnets; recover via "Assigning an IP by MAC Address". NTP: NTP Server Mode DHCP/Manual + NTP Server. [CCT-StaticIP.htm]
- Analytics config: Analytic Events > Configure > Classified Object Motion Detection > Edit (ROI yellow markers, exclusion areas, Person/Vehicle subtypes, Sensitivity, Threshold Time); Add Event (name, Enabled, Activity, ROI, Object Types, Show Advanced Options: Sensitivity default 8, Number of Objects, Threshold Time, Timeout 60 min, Prohibited Direction). Radiometric thermal events: Thermal tab: Emissivity, Temperature Threshold (above/below/matches, °C/°F, Minimum duration 1-1800 s) or Temperature Change (Increases/Decreases by, Duration, Starting Value), Measurement Mode Spot Detection / Box Detection (Average/Maximum/Minimum temperature in ROI; avoid FoV edges), Timeout; Advanced: Sensitivity 1-10, Significant temperature change, Absolute significant temperature change, Significant pixel count change, Absolute significant pixel change, Maximum time to ignore, Minimum throttle update, Hysteresis, Match Range. Crowd Detection > Configure: Unusual crowd growth / Crowd size / Unusual crowd size; Inclusion Area; Enabled; Number of people, Threshold Time, Timeout, Sensitivity 1-10. [CCT-ConfigureAnalytics.htm]
- Export/Import: task menu > Export Device Settings (with/without analytics) → CSV; edit (don't delete/reorder columns; don't change MAC; set DHCPEnabled False for static IP) → Import Device Settings > Edit Devices > Apply. Command-line parameters also available. [CCT-Export.htm]
- Certificates (TLS tab): Download CSR checkbox per camera > Apply > Common Name (≤64 chars; Prefix/Suffix/Source of unique data); upload signed certs; apply; delete; Encryption Mode (FIPS/CRYPTR). Firmware upgrade keeps active cert; factory reset reverts to default cert. [certificates/managing-certificates.htm]
- CSR detail: Common Name Prefix + Source of unique data (None/Counter/Name/Location/Hostname/IP/MAC/Serial/current CN/Autogenerated hex) + Suffix; SAN (User input or copy of CN/Hostname/IP/first SAN of current cert); OU/Org/Locality/State/Country (Country mandatory for Pelco). Download CSR → zip. Upload: zip of .crt/.cer/.pem + CA cert (to show trusted) via task menu > Upload Certificates > Upload. Apply: TLS tab > TLS Certificate Subject column > pick > Apply. Delete: TLS tab > Manage Certificates > Manage > Delete (not active or factory default). [certificates/uploading-certificates.htm]
- Encryption Mode (TLS tab): OpenSSL (default) / FIPS 140-2 Level 1 (FIPS camera license) / NXP TPM / CRYPTR FIPS 140-2 Level 3 (CRYPTR micro card in SD slot). TPM/CRYPTR generate new key+self-signed cert (re-sign via CSR). Reboot; 1-5 min per camera. CRYPTR card removed → camera restarts in FIPS 140-2 L1; must reselect CRYPTR mode after reinsert. [certificates/encryption-mode.htm]
- Network security: CCT tries HTTPS then falls back to HTTP; disable fallback with C:\Program Files (x86)\Motorola Solutions\Camera Configuration Tool\CCT_DisableHttp.reg (re-enable CCT_EnableHttp.reg). Per camera: Network tab > clear Enable HTTP (HTTPS only), set HTTP/HTTPS Port #. [security/network-security.htm]
- Firmware: download .fp files to C:\Program Files (x86)\Motorola Solutions\Camera Configuration Tool\firmware; task menu > View Local Firmware Repository; Firmware Update tab > Available Firmware Version header edit > select > Apply > check Upgrade / Downgrade checkbox > Apply. Critical firmware banner at bottom > Update cameras > Apply (apply pending settings first). [CCT-FirmwareIntro.htm]
- CCT-Batch.exe (cmd in install folder): -a/--addIP <ip> or <start>-<end>; -u user; -p password ("" empty; PowerShell can't do empty); -t httpPort (80); -s httpsPort (443); -f force (skip unreachable); -e/--export "file.csv"; -i/--import "file.csv"; -d/--downloadCsr "<subject and SAN>" "file.zip|.csr" (--csrHelp); -c/--uploadCrt "file.zip|.crt" [+ -r OLD | -r ALL]; -r/--removeCrt <id>;<id>; -l/--listCrt (active = ! green, expired red, self-signed grey). Exit code 0 = success (%errorlevel% / $LastExitCode). [CCT-commandline-codes.htm]
- Device Logs: filter list > task menu > Device Logs > Write Logs to File (.txt; live stream until Stop; identify by serial). [CCT-DeviceLogs.htm]
- Doc: OLH-CCT-C Rev 1 EN 20260817.

# Software Manager User Guide 8.8 (bundle unity-video-software-manager-8-8)
Base: https://docs.avigilon.com/bundle/unity-video-software-manager-8-8/page/<path>
- Main screen options: Install or Upgrade Applications (online), Create a Custom Bundle (offline/air-gapped, remote Site Update, camera-firmware-only), Install or Upgrade Applications using a Custom Bundle (from AvigilonUnitySetup.exe inside bundle), Uninstall Applications. Tabs: Applications / Camera Firmware / Appliance Firmware; Version dropdown (older = accept risk); View release notes / View system requirements. Command line switches for silent install/mass deployment (see guide "Command Line Switches for Unity Software Manager"). [overview/software-manager.htm]
- Camera firmware only: Create a Custom Bundle > deselect all Applications > Camera Firmware tab > select > download. Deploy: Site Setup > [site] > Site Update > Upload > [CameraFirmwareBundle[version].avrsu > Update (Status Upgraded; servers then push to cameras). Single camera: copy .fp from bundle to USB → camera web UI/CCT. [system-management/install-firmware-on-device-custom-bundle.htm]
- Appliance firmware (AI NVR/ENVR2 PLUS/AIA2): Create a Custom Bundle > Appliance Firmware tab > version > appliances > Download; upload via Site Update, Server Management (Management Interface), or appliance WebUI. [system-management/upgrade-appliance-firmware.htm]
- Site Update (remote): update Client first; Site Setup > [site] > Site Update > Upload > [SiteUpdate[version].avrsu (bundle must include all apps on site; needs disk space) > Update per server; Retry on failure; verify first server. [system-management/updating-site-remotely.htm]
