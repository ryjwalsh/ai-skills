## HID Mercury hardware guide for Unity Access (bundle unity-access-hid-mercury-hardware-guide)
Base: https://docs.avigilon.com/bundle/unity-access-hid-mercury-hardware-guide/page/<path>
- Models: LP1501 (1 door, 3-gang box), LP1502 (2 door), LP2500 (no readers, 64 doors via SIO), LP4502; EP1501/1502/2500 (AC-MER-CONT-1DR/2DR/64DR); MP series; subpanels MR62E (OSDP, IP), MR52 (2 reader), MR51e (IP), MR50 (1 reader), MR16in, MR16out. [0Common/HardwareList_Intro.htm]
- Factory default comm params (LP/MR62E): static IP 192.168.0.251, mask 255.255.0.0, gateway/DNS 192.168.0.1, primary host port IP server no encryption port 3001 address 0. [0Mercury/lp-series-DefParam.htm]
- S1 DIP (LP/MR62E, read at power-up): all OFF normal; SW1 ON = enable default login admin/password for 5 min (read immediately); SW2 ON = factory default comm params (config not saved to flash); SW1+SW2 ON at power-up = factory reset; SW4 ON (LP1502) = emulate EP1502. S2 = reboot. [0Mercury/lp1502-dip-switch.htm]
- Factory reset LP: power off > SW1 ON + SW2 ON > power on (LED1 on ~15 s) > move SW1 or SW2 OFF within 10 s > LED1+2 / LED3+4 alternate > LED2 flashes ~60 s erasing (don't cut power) > LED1+4 flash 3 s = done > reboots. [0Mercury/lp1502-FactoryReset.htm]
- LP1502 LEDs: LED1 offline 20% on / online 80% on; LED2 host comm; LED3 reader data; LED4/5 IN1/IN2 (flash = fault); LED6 cabinet tamper; D9/D10 relay K1/K2; YEL 100 Mb; GRN link. Battery alarms LP4502/1502/2500 → KB 10202 (jumper J19). [0Mercury/lp1502-leds.htm]
- Add controller by MAC (DHCP): all S1 OFF > power > LAN > note MAC on Ethernet jack > Unity Access: Physical Access > Panels > Add Panel > name/location > Appliance > Vendor Mercury Security > Model > Timezone > Save > Subpanels tab > add > Save > Host tab > Installed + IP Client Connection > MAC Address > Save. [0Common/Controller-DHCPAddressing.htm]
- Static IP: SW2 ON (1,3,4 OFF) > power > PC 192.168.0.100 crossover > browse https://192.168.0.251 > SW1 ON (5 min window) > Click Here to Login admin/password > Users: change admin password > Apply Setting > Network > Use Static IP configuration > IP/mask/gateway > Accept > Apply Settings, Reboot > power off > all DIP OFF > connect to LAN > power > Unity Access Add Panel … Host tab > Installed > IP Address > Save. [0Common/Controller-StaticAddressing.htm]
- Interface panel (MR52/MR50/MR16in/out) 8-pos DIP: SW1-5 address 0-31 (binary, SW1 = LSB), SW6-7 baud (OFF/OFF 115200 [older fw 2400], ON/OFF 9600, OFF/ON 19200, ON/ON 38400), SW8 encryption ON (needs MR52 fw 1.38.1+, MR50 1.39.1+, MR16 1.30.1+). SIO RS‑485 2‑wire bus up to 1219 m, 24 AWG shielded twisted pair, terminate first (controller) and last device only. [0Common/Panel-DipSwitch.htm]

## Web Endpoint API (bundle web-endpoint-api)
- Install Web Endpoint on same machine as server (avigilon.com/software-downloads); health at https://localhost:8443/ (appliance uses 443). Change port: %ProgramData%\Avigilon\WebEndpoint.config.yaml → `publicRestInterface:\n  port: 123` > restart service. Disable CORS `enableCors: false`; cipher list `tls:\n  cipherList:`. Logs: C:\ProgramData\Avigilon\WebEndpoint Logs (WebEndpoint.Root.log, WebEndpoint.Metrics.log); config C:\ProgramData\Avigilon\WebEndpoint Config\WebEndpoint.config.yaml (log.transports level error/warn/metric/info/verbose/debug/silly; modules include/exclude by logger name in brackets). Auth tokens via Technology Partner Program. [install-wep.htm]

## Analytics Service 8.8 (bundle unity-video-analytics-service-8-8)
- Restart NVR after installing GPU kit BEFORE installing Analytics Service (via Software Manager). ## Virtual Matrix 8.8 (bundle unity-video-virtual-matrix-8-8)
- After install app auto-starts (Start > Avigilon > Avigilon Control Center Virtual Matrix); log in to Primary Site (+Find a site for other subnets); each monitor gets a View; Monitor Settings dialog appears on mouse move (Exit Application to shut down). Views edited from Unity Client logged into Primary Site. Additional sites for video/maps only. Trusted certs: friendly name AccServerCert; Site Setup > Security > Require trusted server certificates + Client Settings > Security. [getting-started/virtual-matrix-installation.htm]

## Unity Video Mobile app 4.x (bundle unity-video-mobile-ios-4-5)
- Needs Unity 8.7+, Web Endpoint on server (port 8443 Windows / 443 appliance), H.264/H.265 streams. Connect to local site: Connect to local site > IP/Hostname > Port (443 default; 8443 Windows) > Connect > Trust > Username/Password > Sign in. Cell issues: ⋮ > Settings > Show advanced options > Disable iPv6 (Verizon/Rogers) / Disable UDP. Troubleshooting: no alarms → user permissions, site connected to Unity Cloud, alarm rule, phone notifications; no alarm footage → alarm recording enabled in recording schedule. [mobile/connect-local-sites.htm]
