## Login / initial setup
- Browser to appliance IP; Login (+ Remote Login username@domain.org if enabled), Password, Sign in; MFA device + 6-digit code if enabled (not for remote accounts). First login/upgrade forces admin password change. [Logging_in_to_the_ACM_Application.htm]
- Initial setup: gear icon (Setup & Settings) > Appliance > About tab > View End User License Agreement > accept; Add License (Activation IDs > Activate Licenses; offline: Manual tab > Save File .key > activate.avigilon.com > capabilityResponse.bin > Choose File > Activate Licenses). Requires Appliance Name + Host Name set on Appliance: Edit first. Change admin password: Identities > Search > A > "Administrator, System" > Account Information > Password/Confirm > Save (logs you out). Create Super Admin identity: Identities > Add Identity > profile > Last/First Name, Login, Password (≥4 chars) > Save > Roles tab > Super Admin. [InitialSetup_CreateFirstIdentity.htm]
- License upgrade to Unity Access 7: needs "Unity Access ACM6 Upgrade Package" + "Unity Access 7 Software Plan" added on ACM 6 before upgrade. ACM 6 format upgrade: Appliance > About > Download Upgrade File > email .bin to acm.license@avigilon.com (1-2 business days) > Add License; do on both primary and standby if replication. [ACM_UpgradeLicenseFormat.htm]
- Remove license: Appliance > About > check license > Remove License > copy Activation IDs > Remove Licenses (or Manual .key → activate.avigilon.com). [Appliances_-_RemoveLicense.htm]

## Replication & failover (Appliance > Replication tab; only default Admin identity can edit)
- Peer to Peer replication shares LDAP config; each appliance owns its hardware (panel + subpanels on one appliance). Set up BEFORE adding panels/identities. Failover = Primary/Hot Standby (standby has no hardware/collaborations; one standby per primary; standby can serve multiple primaries but only one at a time). Automatic failover via Heartbeat count (≥2 recommended) × Heartbeat time (30 s) ≈ 1-5 min; manual failover/failback from standby's Replication tab. Requirements: licenses on both (standby ≥ primary features), DNS hostnames for all, static IPs, name server, common Time Server (UTC), open TCP ports: Web 443, LDAP Connect/Replication LDAP port (unique), Event Replication Port 6052. [Appliance_-_ConfigReplication.htm]

## Troubleshooting (Unity Access)
- Check licenses first (About page). Appliance events: CPU Load High, Database Disk Space Low (<10%), Network Port 1/2 Link Down, Programs Disk Space Low (<5%), System Memory Low (<10%). [troubleshoot/appliance-events.htm]
- Door events (Invalid Credential): Expired Card Attempt (Schlage LE/NDE tokens expire at START of the hour given in Deactivate Date; ASSA/Control at start of the minute — set next hour/day), Invalid Card - Before Activation, Invalid card format, Invalid Card Schedule, Unknown card (token not downloaded), Invalid PIN, Valid card at an unauthorized reader, Duress Detected. Maintenance: Incompatible Firmware Image, Magnetic Tamper, Token capacity exceeded, RF loss / Lock offline, Out of Sync (ASSA DSR), Door service was offline before system audit. Tamper: Bezel, Bluetooth Tamper - Door (config device connected → disconnect it), Keyswitch, Reader/Device Tamper. [troubleshoot/door-events.htm]
- Panel events: Panel offline; Maximum panel schedule count exceeded (Mercury/ASSA 255; Schlage IP 16 intervals total; SALTO 1024) → fewer schedules / move hardware; Panel Firmware/Parameter/Token Download Started; Panel transaction limit reached. Subpanel offline; Bluetooth Tamper. System events: CSR Created, New Cert Generated/Taken Into Use/Uploaded, Expired Transactions Removed (Max Days Stored), Transaction log exceeded 85%/95%/threshold (Max Stored Transactions). [troubleshoot/panel-events.htm]
- Debug logs: gear > Appliance > Access tab > Debug checkbox next to vendor > Save (delegations Appliance Log/Download/Show/Update; Support may need to enable). Then Appliance > Logs tab. [troubleshoot/debug-logs.htm]
- Status colors: green Normal/Inactive; yellow Trouble (offline/wiring fault); red Alarm/Active; blue Masked. Appliance transaction indicator: >85% Trouble, >95% Alarm → back up transactions, raise Max Stored Transactions, adjust Max Days Stored (Appliance tab). Device status icons: Normal, Uninstalled, Communication, Unlocked, Held, Power (power input open), Battery, Tamper, Forced, Synchronization pending / out of sync (ASSA reload lock; SALTO standalone use PPD). [Status_Colors.htm]
