# Pelco Sarix camera web interface (Sarix Value 2 layout; Sarix Pro 4 / Enhanced 4 / Multi Pro / Thermal Enhanced 4 use the same Motorola-style UI family)
Source: Sarix Value 2 Cameras Operations Manual C6778M (pelco.com/fs/documents/pelco-sarix-value-2-operations-manual-en.pdf), extracted 2026-09-14. Verify page names on other Sarix generations - older Sarix (IMP/IXP/IBP, Spectra) use the legacy "Settings > System/Network/Imaging/A/V Streams/Users/Events" layout [INFERRED - verify].

- Access: http://<camera IP>/ (Edge/Firefox/Chrome, cookies on); find the IP with the Pelco/Motorola Camera Configuration Tool (pelco.com/camera-configuration-tool). Factory-default cameras have NO default user - first visit opens New User page: create an Administrator. Auto-logout after 15 min.
- **Live View**: zoom/focus sliders, Auto Focus, codec selector, analytics overlay toggles (Draw Object Bounding, Relearn background). **Playback**: storage device, event-type filters, time range, Search.
- **General**: Name, Location; Time (manual / Synchronize with PC / NTP - DHCP or manual server, sync period); Time Zone.
- **Network & Security**: Network Settings (Hostname, MTU 1500, HTTP 80, HTTPS 443, RTSP 554; IPv4 DHCP/APIPA toggles or static IP/mask/gateway; IPv6); Multicast Streaming (Auto/Manual address, port, TTL per primary/secondary/tertiary); Configure TLS (Optional/Required; Self Signed / Request CSR / Upload Certificate, CA upload); 802.1x (EAP-MD5 / EAP-TLS, Save and Test); SNMP v2c/v3; Firewall (Allow/Deny up to 10 addresses); SFTP / FTP servers; DDNS (DynDNS, No-IP, Two-DNS, FreeDNS); SMTP (host, port, auth, sender, up to 10 recipients); RTSP (authentication, multicast auto connection, port); **User Accounts** (Admin / Operator / User; password needs upper, lower, digits; delete).
- **Image & Display**: Basic (orientation, 2D/3D noise reduction, sharpness, saturation, contrast, brightness, hue, zoom/focus, Corridor Mode, White Balance ATW/Auto/Manual); Exposure (Auto / Flickerless / Shutter Priority / Manual / True WDR; Digital WDR, shutter limits, P-Iris, EV, BLC, frequency, gain); Day/Night (Auto/Color/B/W, switch speed, thresholds, IR Mode Auto/On/Off/White LED, Smart IR, Adaptive IR, IR level); Text and Event Overlay (device name/date/custom text, colours, X/Y); Privacy Zones (up to 8, colour).
- **Compression & Image Rate**: per stream Compression H265/H264/JPEG, Resolution, Rate Control CBR/CVBR/VBR, Frame rate, GOP Length (30), Maximum Bitrate, SVC-T, QoS DSCP, Profile High/Main/Baseline; Smart Codec level Off/Low/Medium/High + Dynamic GOP.
- **Analytics**: Motion Detection (draw region, sensitivity, object size, up to 4 zones; actions: snapshot to edge/FTP, edge record, white LED, email, text overlay, HTTP generic event; schedules); Sabotage Detection; Adaptive Motion (up to 3 lines with direction A→B/B→A); Camera Automation (FTP server, snapshot pre/post frames, HTTP Generic Event ×10 (URL, GET/POST, credentials, active/inactive message), White LED timers); Manage Schedules (Regular/Persist, trigger interval 5-3600 s); Events Logs (filter, search, clean up).
- **Storage**: SD Card Settings (clip duration 5-10 s, clip size 50-100 MB, codec), Recording Mode (Enable Continuous Local Recording), Recording List (calendar, download), SD Status (Overwrite, Encryption Mode, Format).
- **System**: Backup & Restore (tar.gz download / upload and restore); Firmware (version, hardware, model, serial; upload .ppm file - download from pelco.com/updates); Default & Reboot (Reboot; Software Factory Default keeps network config; Hardware Factory Default resets everything); Device Information; Device Logs (Generate .tgz).
- Static IP: Network & Security > Network Settings > IPv4 > DHCP off > IP/Subnet/Gateway > Apply. Password change: Network & Security > User Accounts. Firmware: System > Firmware > Click to upload > Upload.
